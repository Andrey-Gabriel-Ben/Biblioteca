#

<p align="center" style="font-size: 30px;"> Sobre o projeto: </p>

Esse é um projeto desenvolvido com a finalidade de praticar os conceitos aprendidos nas aulas de desenvolvimento de sistemas de informação do [programa Jovem Programador](https://www.jovemprogramador.com.br/), ofertado pela faculdade [Senac](https://www.senac.br/) em conjunto com o [SEPROSC](https://www.seprosc.com.br/).

A proposta era desenvolver uma aplicação em Java para gerenciar uma biblioteca, permitindo o cadastro e controle de livros, usuários e empréstimos. O cenário que nos foi apresentado era de que uma pequena biblioteca precisava de um sistema simples para organizar seus livros e controlar quem está com cada exemplar, capaz de evitar os erros e as perdas de informações que ocorriam, uma vez que esse controle era feito apenas com caneta e papel.

Para realizar essa tarefa, implementei à aplicação um banco de dados onde os registros dos empréstimos e devoluções são armazenados, tal qual os novos usuários, livros e exemplares. Para isso ser possível, utilizei a plataforma de desenvolvimento em Postgres, Supabase.



#

<p align="center" style="font-size: 30px;"> Como acessar o sistema? </p>

Para acessar o sistema, basta baixá-lo primeiramente por esse repositório. Para evitar vazamento de dados, não disponibilizei as credenciais do meu banco de dados no repositório. Portanto, para tudo funcionar como deve em seguida, crie um arquivo "config.properties" na pasta "arquivos" do projeto. Para isso, use como base o arquivo "config.properties.example" já presente nessa pasta e lá altere os dados presentes no exemplo para as credenciais do banco desejado.
